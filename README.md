One original one-line office joke, written by a program to `/output/entry.txt` for the make.fun "Make the AI Judge Laugh: Office Jokes" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
